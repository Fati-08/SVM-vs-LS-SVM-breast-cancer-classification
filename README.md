# Breast Cancer Classification using LS-SVM
This repository contains an optimization project developed as part of the Master's degree curriculum in Data Science at the University of Parma.
# Project Overview
The objective of this project is to implement a Least-Squares Support Vector Machine (LS-SVM) classifier using MATLAB to process and classify medical data. The model was trained and evaluated using the Breast Cancer Wisconsin dataset.

# Key Implementation Details
   **Core Algorithm:** Built the LS-SVM model entirely from scratch without relying on high-level pre-built machine learning libraries.
   **Linear System Solver:** Implemented the core KKT (Karush-Kuhn-Tucker) linear system to solve the optimization problem efficiently.
   **Hyperparameter Tuning:** Applied a 5-fold Cross-Validation strategy on the training set to optimize the regularization parameter $\gamma$ and the RBF
                              kernel parameter $\sigma$.

## Technologies Used
Language: MATLAB
Focus Areas: Mathematical Optimization, Machine Learning, Binary Classification
